# 🛍 My Telegram Shop (پلتفرم فروشگاهی و خدمات فوری تلگرام)

یک پلتفرم ماژولار، مقیاس‌پذیر و بسیار امن برای فروش **استارز (Telegram Stars)**، **تلگرام پرمیوم**، **گیفت‌های تلگرام** و **ارزهای دیجیتال (TON / TRX)** با فریم‌ورک مدرن `aiogram 3.x` و دیتابیس ناهمگام (Asynchronous SQLite با مود WAL).

---

## 🌟 ویژگی‌های کلیدی پروژه

1. **معماری ماژولار و تمیز (Clean Architecture):**
   - تفکیک کامل لایه‌های `handlers`، `keyboards`، `services`، `core` و `middlewares`.
   - توسعه‌پذیری آسان بدون اسپاگتی‌کد.

2. **امنیت مالی ضدگلوله (Bulletproof Financial Security):**
   - **تراکنش‌های اتمیک (`BEGIN IMMEDIATE`):** جلوگیری ۱۰۰٪ از باگ‌های همزمانی، دابل‌اسپند (Double-Spending) و پرداخت‌های تکراری.
   - **کنترل و انقضای فاکتورها:** فاکتورها پس از ۱۵ دقیقه منقضی می‌شوند.
   - **سیستم ضدتقلب کدهای تخفیف:** جلوگیری از ترکیب و اعمال چندباره تخفیف روی یک سفارش؛ محاسبه درصد از قیمت پایه (Gross).
   - **دیتابیس ناهمگام (Async):** پیاده‌سازی با `aiosqlite` به همراه فعال‌سازی مود پرسرعت **WAL** (`PRAGMA journal_mode=WAL`) برای ممانعت از قفل شدن دیتابیس تحت بار سنگین.

3. **تجربه کاربری و ظاهر شیک (UI/UX):**
   - برچسب‌های کشیده فارسی (تطویل) در منوی اصلی.
   - استایل‌های رنگی دکمه‌های تلگرام (Bot API 9.x: `success`, `primary`, `danger`).
   - محاسبه خودکار تعداد استارز بر اساس موجودی فعلی کاربر.
   - کاتالوگ کامل ۱۱ گیفت تلگرام با ارزش‌های استارزی واقعی.

4. **سیستم گیمیفیکیشن و وفاداری:**
   - چالش‌های روزانه تاس (🎲) و بولینگ (🎳) با اهدای موجودی تخفیف هدیه.
   - سیستم زیرمجموعه‌گیری با لینک اختصاصی و پورسانت خودکار.
   - امتیاز باشگاه مشتریان به ازای خریدها.

5. **پنل مدیریت ادمین (`/admin`):**
   - مشاهده آمار زنده فروش و کاربران.
   - مشاهده و تحویل یا رد سفارش‌های در انتظار به همراه عودت خودکار وجه.
   - ارسال پیام همگانی (Broadcast).
   - ویرایش دستی موجودی کاربران.

## 📁 ساختار پوشه‌بندی پروژه

```text
my_telegram_shop/
├── bot/
│   ├── core/
│   │   ├── __init__.py
│   │   └── database.py        # هسته دیتابیس ناهمگام با ترنزکشن‌های امن
│   ├── handlers/              # کنترل‌کننده‌های پیام و روترها
│   │   ├── __init__.py
│   │   ├── start.py           # دستور شروع، گیت کانال‌ها و منوی اصلی
│   │   ├── shops.py           # استارز، پرمیوم، گیفت و ری‌اکشن
│   │   ├── payment.py         # تسویه با کیف پول، کد تخفیف و تحویل
│   │   ├── wallet.py          # مدیریت موجودی و شارژ ریالی/کریپتو
│   │   ├── account.py         # پروفایل، پیگیری سفارش و رفرال
│   │   ├── games.py           # چالش‌های روزانه تاس و بولینگ
│   │   └── admin.py           # پنل مدیریت، آمار و ارسال همگانی
│   ├── keyboards/             # چیدمان کیبوردهای شیشه‌ای و ریپلای
│   │   ├── __init__.py
│   │   ├── common.py          # موتور دکمه‌ساز با پشتیبانی استایل رنگی
│   │   ├── reply.py           # منوی اصلی با خطوط کشیده
│   │   └── shops.py           # اینلاین‌های خرید، گیفت‌ها و فاکتورها
│   ├── middlewares/           # میدل‌ور ضداسپم و کنترل نرخ درخواست
│   │   ├── __init__.py
│   │   └── throttling.py
│   └── services/              # لایه سرویس‌های خارجی
│       ├── __init__.py
│       ├── fulfillment.py     # موتور تحویل سفارش (اتصال به فرگمنت یا تأمین‌کننده)
│       └── payment_gateway.py # ماژول درگاه بانکی شتاب و کریپتو
├── config.py                  # تنظیمات و متغیرها با Pydantic
├── main.py                    # نقطه ورود و اجرای برنامه
├── requirements.txt
├── .env.example
└── README.md
```

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. پیش‌نیازها
* پایتون نسخه 3.10 یا بالاتر
* گیت (Git)

### ۲. نصب پکیج‌ها
```bash
# ساخت محیط مجازی
python3 -m venv .venv

# فعال‌سازی محیط مجازی
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
یک کپی از فایل نمونه تهیه کنید:
```bash
cp .env.example .env
```
فایل `.env` را با ویرایشگر باز کنید و توکن ربات خود را قرار دهید:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_IDS=12345678,87654321
REQUIRED_CHANNELS=@MyChannel
SUPPORT_USERNAME=@MySupport
```

### ۴. اجرای ربات
```bash
python3 main.py
```

## 🔌 نحوه اتصال به API فرگمنت و درگاه پرداخت

کدهای اتصال به سرویس‌های بیرونی در پوشه `bot/services/` قرار دارند:
* **تحویل خودکار سفارش‌ها:** فایل `bot/services/fulfillment.py` متدهای آماده `_deliver_stars` و `_deliver_premium` را دارد که می‌توانید API فرگمنت یا تأمین‌کننده خود را در آن قرار دهید.
* **درگاه پرداخت آنلاین:** متد `create_rial_payment` در فایل `bot/services/payment_gateway.py` آماده اضافه کردن کد درگاه زرین‌پال، نکست‌پِی یا آیدی‌پِی می‌باشد.
